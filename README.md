# DiscordSecurityBot

## Требования
1. Discord аккаунт, Discord гильдия и право доступа **«Администратор»** в ней.
2. Windows, проверялось только на 11, вероятно заработает и на 10. Версии под Linux пока нет.
3. [KeePassXC](https://github.com/keepassxreboot/keepassxc), в теории подойдёт любая не совсем древняя версия, но проверялось только на 2.7.12

   По сути важен только функционал `keepassxc-cli.exe`.

## Настройка и запуск

### Discord Developer portal
1. Залогиниться на [Discord Developer Portal](https://discord.com/developers/home)
2. Во вкладке [приложения](https://discord.com/developers/applications) нажать **«Новое приложение»** и создать его.
3. В разделе **«Установка»** оставить только **«Установка гильдиями»**, бот работает только там.
4. В разделе **«Бот»** выдать разрешение **«Server Members Intent»** если нужна команда **ExportInvites**.
5. В разделе **«OAuth2»** отметить область доступа **«bot»** и право **«Управлять вебхуками»** для команды **ExportWebhooks**.
6. Выбрать нужный **«Тип интеграции»**.
7. Перейти по **«Сгенерированный URL»** и добавить приложение куда нужно.
8. Опционально настроить приложение в гильдии: «Настройки сервера → Интеграция».

### KeePassXC
1. В KeePassXC создать базу данных с любым именем и шифрованием.
   Поддерживаются базы данных с/без пароля и/или с/без ключевого файла. **«Вызов-ответ»** не поддерживается.
3. В любом месте базы данных создать запись с любым названием, по умолчанию предполагается `Token`.
4. В поле **«Пароль»** ввести токен бота.

   Если уже есть база данных, то токен можно поместить в неё, не обязательно создавать новую, но так безопасней.
   Рекомендую иметь отдельную БД под токен, а в основой хранить пароль от неё.

### Бот
1. Скачать и распаковать архив [win-x64.zip](https://github.com/Sipovec/DiscordSecurityBot/releases).
2. В `appsettings.json` указать:
  - `TestGuildId` — ID гильдии(сервера), к которому нужно подключить бота.
  - `CliPath` — Путь до `keepassxc-cli.exe`.
  - `DbPath` — Путь до базы данных KeePassXC, в которой лежит токен бота.
  - `KeyFilePath` — Путь до ключевого файла, используемого для разблокировки базы данных. Если нет, то сделать пустой строкой `""`.
  - `EntryName` — Название записи в базе данных, в которой лежит токен. Если пусто, то будет использоваться `Token`.

    Пути должны быть с двойными или/и обратными слеэшами:
    - `"C:\\ProgramFiles\\KeePassXC-2.7.12-Win64\\keepassxc-cli.exe"`
    - `"C:/ProgramFiles/KeePassXC-2.7.12-Win64/keepassxc-cli.exe"`

 3. Запустить `DiscordSecurityBot.exe` и ввести пароль от базы данных, в которой лежит токен.
 4. Вводить команды в гильдии, к которой подлючён бот.    

## Команды
Видны и могут быть выполнены только в каналах гильдии пользователями с правом доступа **«Администратор»**.
- `ExportRoles` — Роли и их права доступа.
- `ExportChannels` — Права доступа в каналах.
- `ExportUsers` — Пользователи с указанной ролью. 
- `ExportInvites` — Ссылки-приглашения.
- `ExportGuildSettings` — Настройки гильдии.
- `ExportBots` — Боты.
- `ExportWebhooks` — Вебхуки.
- `OwnerInfo` — Информация о владельце гильдии, отображается в **Embed** сообщении, видно только вызвавшему.

Все `Export` команды экспортируют данные в `.csv` таблицу, файл с которой создаётся в папке `Export`, рядом с `DiscordSecurityBot.exe`.
Права доступа экспортируются как `TRUE`/`FALSE` для поддержки системы "Флажков" в Google таблицах: 
Выделить ячейки → «Вставка» → «Флажок».
